# Q1 Sales Performance Report (Excel)

## Project Overview
Sales team ke Q1 (Jan-Mar) performance ka Excel report. Isme employees ka total sales, target achievement, promotion aur bonus eligibility nikala gaya hai.

## Dataset
- 40 employees (practice ke liye banaya gaya sample data)
- Columns: Name, Gender, Age, Region, Contact No, Days Worked, Performance, Target, Jan/Feb/Mar Sales

## Data Cleaning
- 3 duplicate rows hataye (43 se 40 rows)
- Blank Age aur Performance wale rows pehchane aur alag se note kiye
- Galat length wale contact numbers check kiye

## Excel Skills Used
SUM, MAX, MIN, AVERAGE, IF, AND, OR, IFS, COUNTIF, Sort, Filter, Conditional Formatting, Data Validation, Remove Duplicates

## Key Insights
- Company ki total Q1 sales: Rs 62,90,000
- Average sales per employee: Rs 1,57,250
- Top employee: Nisha Jain (Rs 2,13,000)
